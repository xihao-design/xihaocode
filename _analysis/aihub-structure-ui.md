# aihub.cn 结构与 UI 风格分析

> 分析方法：抓取该站渲染前的 HTML（310KB）、下载并解析它的主题 CSS（**B2 主题** 300KB + 子主题 3KB + 根样式 13KB），
> 对选择器、色值、圆角、字号、间距做频次统计。
> 下面所有数字都是**从它自己的样式表里统计出来的**，不是肉眼估的。
> 说明：该站首页是 Vue 客户端渲染，`--dump-dom` 拿不到内容，所以「版心具体多少 px」这类需要渲染后才能量的值我没有，下文会标注。

---

## 一、它是什么

**技术底子**：WordPress + **B2 主题**（`wp-content/themes/b2`，v5.9.41），带一个子主题（`b2child`，作者自己写的自定义 CSS，只有 3KB）。
前端用 Vue + Vuex + axios，图片用 lazyload，列表用 flickity（轮播）/ packery（瀑布流）。

**这件事对「参考它」很重要**：B2 是一个**通用资源站/社区主题**，不是为 AI 工具站定制的。
所以它呈现出来的风格是「**信息密集的资源目录**」，而不是「品牌化的产品官网」。
子主题只改了 3KB —— 说明这个站**几乎没做视觉定制**，风格基本就是 B2 的默认观感。

## 二、信息架构（结构）

### 2.1 导航：顶部导航条 + 分类巨型菜单，**没有常驻侧栏**

这是与我们差异最大的一点。

它的一级导航是**顶栏**：`AI工具 / AI资源 / AI资讯 / 关于我们 / 合作联系`。
其中「AI工具」下面挂了一个**巨型下拉菜单**，按分类列出子类：

```
AI工具
├─ AI写作工具      → 推荐写作工具 / AI通用写作工具 / AI论文工具 / AI小说工具
├─ AI图像生成      → 推荐图像工具 / 插画生成 / 背景移除 / 图像放大 / 图像修复 / 物体抹除 / 商品图生成 / Logo工具 / AI 3D模型生成工具
├─ AI视频工具      → 推荐视频工具 / 视频生成 / 视频剪辑 / 数字人生成 / AI短剧工具
├─ AI办公工具      → 推荐办公工具 / PPT制作 / 表格处理 / 文档编辑 / 思维导图 / 会议工具 / 效率助手 / 招聘面试 / AI法律工具
├─ AI智能体        → 推荐智能体 / 通用智能体 / 操作型智能体 / 开发者智能体 / 智能体开发平台 / 视频智能体 / 金融智能体
├─ AI对话聊天  AI设计工具  AI编程工具  AI搜索引擎  AI浏览器  AI音频工具
└─ AI开发平台  AI训练模型  AI内容检测  AI语言翻译  AI提示指令  AI模型评测  AI学习网站
```

**共 18 个一级分类，其中 5 个还有 4–9 个子类。** 子类是真的做成了独立页面
（`/favorites/ai-image-tools/` 这种），不是前端筛选。

> 关键判断：**它的层级是「顶栏 → 巨型菜单 → 分类落地页」，不是「左侧栏展开树」。**
> B2 主题本身支持侧栏（`.widget` 出现 34 次），但首页内容区是**模块横向堆叠**，分类导航靠顶栏承担。

### 2.2 首页内容排布：模块纵向堆叠，每块是一个功能区

首页是「模块（module）» 顺序堆叠」的结构，实测到的模块顺序：

| 顺序 | 模块 | 形态 | 条目数 |
|---|---|---|---|
| 1 | 顶栏 + **搜索模块** | 居中大标题（32px）+ 副标题（18px, max-width 60%）+ 搜索框 | — |
| 2 | **编辑推荐** | 横幅卡片（banner，大图） | 4 条 |
| 3 | **热门工具** | 紧凑卡片网格 | 8 条 |
| 4 | **最新收录** | 紧凑卡片网格 | 6 条 |
| 5 | **AI写作工具** | 分类区块：子类标签行 + 卡片网格 | 8 条 |
| 6 | **AI图像生成** | 同上 | 多条 |
| 7 | **AI视频工具** | 同上 | 多条 |
| … | 继续按分类重复 | 同上 | … |

它内联的 Vue 模板里能看到完整的模块清单（`home_row_0.module-search`、
`cat-list post-load-button` 这种「加载更多」按钮 ×8）。

**和我们现在的差别**：我们已经改成了「分类区块堆叠」（这一步是对的，方向一致），
但我们**顶部没有那个「搜索模块」作为首屏主视觉** —— 它的首屏是
**居中标题 + 搜索框**，不是 hero 文案 + 大标语。

### 2.3 卡片有两种形态并存

1. **紧凑卡片**（主流）：缩略图 + 标题（2 行截断）+ 摘要（1–2 行截断）
2. **热榜小条目**：固定 92px 高，左侧一个**带箭头的红色名次角标**

第 2 种是它的特色：`.b2-widget-post-order` 红色角标
`border-radius: 0 10px 10px 0`（右侧圆角、左侧切平贴边），
第一名用 `#ff3355` 红底白字，还有一个 `border-bottom: 4px solid #ff3355` 做的小箭头。

## 三、UI 视觉风格（实测数值）

### 3.1 颜色：极简灰白 + 单一红色点缀，**没有品牌色系统**

| 用途 | 色值 | 出现次数 | 说明 |
|---|---|---|---|
| 卡片/白底 | `#fff` | 204 | 卡片、顶栏 |
| 页面底/图片占位 | `#f5f6f7` | **164** | 浅冷灰，也用作缩略图占位底色 |
| 次要文字 | `#bcbcbc` | 48 | |
| 次要文字 | `#aaaeb3` | 33 | |
| 分割线 | `#ccc` | 33 | |
| **强调红** | `#ff3355` | 23 | **热榜名次角标、付费标记** |
| 次要文字 | `#8590a6` | 19 | |
| 浅灰底 | `#f6f6f6` / `#fafafa` / `#f9f9f9` | 15 / 14 / 9 | |
| 近黑 | `#333` | 14 | |
| 深色 | `#121212` | 9 | |
| 正文灰 | `#797c80` | 8 | **摘要文字色** |
| 红（次） | `#f16b6f` | 8 | |

**子主题里唯一的自定义颜色**是分类页头图的蓝：`rgb(54 77 203)` 和 `rgb(35 91 226)`（分类页头图遮罩）。

> **三条关键结论**：
> 1. **它没有「品牌主色」**。整站是 `#fff` + `#f5f6f7` 的灰白，红色 `#ff3355` 只用于**热榜名次**这个功能位。
> 2. 蓝色（`#235be2`）**只出现在分类页的头图遮罩**上，不是全站按钮色。
> 3. 换句话说：**它的视觉记忆点不在颜色，而在密度和排版。**

这一点和 skillhub（紫↔珊瑚双色）完全是两个路数 —— 也解释了为什么上一轮把 skillhub 的双色套上来观感不对。

### 3.2 排版：小字号、高密度、字重 600 扛层级

| 项 | 实测 |
|---|---|
| 字号频次 | **12px 出现 206 次**（压倒性第一）、14px 95 次、13px 74 次、16px 34 次、15px 32 次、20px 30 次 |
| 卡片标题 | **15px**（`.post-info h2`），2 行截断 |
| 卡片摘要 | **12px**，色 `#797c80`，1–2 行截断 |
| 搜索标题 | **32px**（子主题自定义），居中，字重 500 |
| 搜索副标题 | 18px，居中，max-width 60% |
| 分类页标题 | 36px（分类头图里） |
| 字重 | **600 出现 67 次**（第一），normal 31、400 18、bold 14 |
| 衬线/无衬线 | 正文无自定义字体（走系统栈）；只有 **数字用 DIN**（`font-family: DIN`，用于名次/数据） |

> **它的层级靠字重 600 + 字号差，不靠颜色。** 正文 12–14px 是「目录/社区」的典型规格，
> 比我们现在（正文 15.5–16px、hero 到 52px）**小一档**。

### 3.3 形状：小圆角、几乎无阴影

| 项 | 实测 |
|---|---|
| 圆角 | **3px × 35 次**（主力）、5px × 17、4px × 12、2px × 4；胶囊 20px × 6、50px × 4；圆形 100% × 48（头像） |
| 阴影 | 常用值极少：`0 2px 10px 0 rgba(0,0,0,.16)` × 3、`0 4px 16px 0 rgb(13 39 91 / 6%)` × 2、`0 2px 8px rgba(0,0,0,.1)` × 2 |

> **3px 圆角 + 极淡阴影** = 冷静、紧凑、偏「工具性」的观感。
> 我们现在用 14px 大圆角 + 明显阴影（偏「卡片式产品页」），这是两种完全不同的气质。

### 3.4 布局：**几乎纯 flexbox，几乎没有响应式断点**

| 项 | 实测 |
|---|---|
| `display:flex` | **493 处** |
| `display:grid` | **1 处**（全站只有一处 `repeat(3, 1fr)`） |
| `flex-wrap` | 17 处 |
| `@media` 断点 | **主样式表里只有 1 个**（且是 IE hack） |
| 缩略图比例 | 用 `padding-top: N%` 定比例（`.post-module-thumb{height:0}` + 绝对定位图片） |
| 图片占位底色 | `#F5F6F7` |

> **它基本不做响应式**，靠 flex 自然收缩 + 单列堆叠。
> 卡片是「图在上、文字在下」的竖向结构：`.post-module-thumb` 高度设 0、用 padding-top 撑比例，
> 图片绝对定位铺满。

### 3.5 卡片具体度量（可直接抄的部分）

```
卡片标题      font-size: 15px;  -webkit-line-clamp: 2;  margin: 11px 16px;
卡片摘要      font-size: 12px;  color:#797C80;         -webkit-line-clamp: 1;  margin: 0 16px 13px; margin-top:-6px;
缩略图容器    height: 0;  overflow: hidden;  （内部图片绝对定位铺满，用 padding-top 撑比例）
图片占位色    background-color: #F5F6F7;
热榜条目      height: 92px;  （固定行高，横向：缩略图 + 名次 + 标题）
热榜名次角标  position:absolute; left:-4px; top:16px; border-radius: 0 10px 10px 0; 第1名 background:#ff3355
付费角标      position:absolute; top:0; left:0; 有 padding-top:14px; padding-left:12px;
              背景 linear-gradient(.5turn, rgb(9 15 29 / 15%), transparent)
名次数字      font-size:12px; line-height:24px; font-style: italic;  （DIN 字体）
```

## 四、和我们现在这套设计的差异（这才是「改得不尽人意」的原因）

| 维度 | aihub.cn（B2 默认观感） | 我们现在的站 |
|---|---|---|
| 导航 | **顶栏 + 巨型分类菜单**，无常驻侧栏 | **左侧栏 256px 常驻** |
| 首屏 | **居中标题 + 搜索框**（32px 标题） | hero 大标语（h1 到 52px）+ 统计数字 |
| 主色 | **没有品牌色**，灰白 + 红色仅用于热榜 | 上一轮改成紫↔珊瑚双色（skillhub 的路数） |
| 正文 | **12–14px** | 15.5–16px |
| 卡片标题 | 15px，2 行截断 | 15.5px + 摘要 + 分类标签 + 徽标 |
| 圆角 | **3px / 5px** | 14px |
| 阴影 | 极淡 | 明显（`0 8px 24px` 级别） |
| 布局 | 纯 flex，**几乎无响应式** | flex + 系统性断点（1080/720/560） |
| 卡片形态 | 图在上文字在下；另有 **92px 热榜条目** | 统一卡片（图标+名称+描述+标签+箭头） |
| 密度 | **一屏 12–18 张卡** | 一屏 6–9 张 |

**所以上一轮的问题不是「颜色没调对」，是路数不对**：
skillhub 是「品牌化的现代产品站」（双色、大圆角、留白大），
aihub/B2 是「信息密集的目录站」（无品牌色、小圆角、小字号、高密度）。
我把前者套到了一个后者形态的站上 —— 结构是目录，视觉是产品页，两边打架。

## 五、如果要往 aihub 这个方向调，该动什么（按性价比排序）

1. **字号整体下移一档**（最高性价比）
   正文 15.5→14px、卡片标题 15.5→14.5px、摘要→12px、hero h1 从 52px 收到 32–36px。
   这一步就能明显改变观感，而且不动结构。
2. **圆角收小**：卡片 14px → 6px，按钮 8px → 6px，chip 保持胶囊（它也用 20px 胶囊）。
   圆角是气质开关：大圆角=产品页，小圆角=目录页。
3. **阴影几乎去掉**：把卡片阴影降到 `0 1px 2px rgba(0,0,0,.04)` 级别，靠 `#f5f6f7` 底 + 白卡分离层次。
4. **引出「热榜条目」这个形态**：92px 固定高 + 红色名次角标。
   我们的 Star 榜现在是大卡片，改成紧凑热榜行会立刻「像」aihub。
5. **首屏加搜索模块**：居中标题 32px + 副标题 + 搜索框，替掉现在的 hero 大标语。
   —— 但这条会动到首页结构，要单独确认。
6. **主色决策**：aihub 的答案其实是「不要品牌色，红色只给热榜」。
   如果我们想要一点品牌感，建议**回到单一强调色（红或蓝），不要双色渐变**。
