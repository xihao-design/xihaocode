# 网站使用指南


## 网站简介

XihaoUC 是一个以 “好资源不私藏” 为理念的专业互联网资源分享平台，致力于为用户提供覆盖多领域、高品质的各类资源，从软件、设计、教育到 AI、书籍、自媒体运营等，全方位满足用户在互联网资源上的多元需求。
<br>
<br>
1. 在资源广度上，XihaoUC 尽量做到极致。
- 软件资源板块涵盖实用工具、影音娱乐、工作学习等多个维度，让用户一站式获取提升效率、丰富生活的各类应用；
- 设计创意素材板块聚合 UI、UX、视觉设计、作品集等资源，成为设计师汲取灵感、精进技艺的优质阵地；
- 教育资源板块贯穿幼儿园至高中全学段，精选内容助力各年龄段学习者和教育工作者。
<br>
<br>
2. 在资源深度上，XihaoUC 同样表现出色。
- AI 工具资源板块提供从学习教程到提示词、使用指南的全链路支持，助力用户驾驭智能工具；
- 书籍资料板块收录数千种教程、小说、哲学著作，构建起知识的多维矩阵；
- 自媒体运营、职场、壁纸、游戏等板块也各自深耕领域，为用户提供从技能提升到生活美学的全方位资源解决方案。


## 如何获取资源

1. 在本站首页或本页面左侧导航栏，找到所需资源的分类，点击跳转到分类页面
2. 找到所需的分类资源合集，点击链接弹出弹窗，再点击【保存】按钮即可
3. 或在分类资源下找到单资源项目，点击资源名称，再点击【保存】按钮即可
